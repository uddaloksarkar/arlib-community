# References

This file records papers cited by the public Lean modules, including stable
source keys and migration provenance needed by downstream readers.

Use a stable short key in docstrings, followed by the paper's theorem or section
number where possible. Do not cite a path to a local PDF: paths are not useful
to downstream readers and do not survive repository moves.
